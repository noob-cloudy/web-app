# Gaslaw Calculator

A client-side React calculator for solving any variable in the ideal gas law, `PV = nRT`. Inputs can use mixed units; values are converted to SI before calculation, and the result can be displayed in any supported unit. Worked conversions and calculation history are included.

## Run locally

Requires Node.js 18 or newer.

```sh
npm install
npm run dev
```

Calculation history is stored in this browser's local storage.
